Система записи к врачу (Spring Boot + PostgreSQL)

Это веб-приложение для регистрации пациентов, выбора врача и записи на приём. Проект реализован с использованием **Spring Boot**, **Thymeleaf**, **PostgreSQL**, и поддерживает тестирование репозиториев и контроллеров.

----Функциональность

- Регистрация и вход пациента
- Просмотр списка врачей (ФИО + специальность)
- Запись к врачу на дату и время
- Просмотр и отмена своих записей


----Открыть сайт

http://localhost:8080

----Основные страницы:

- Регистрация: `/register`
- Вход: `/login`
- Список врачей: `/doctors?patientId={id}`
- Запись к врачу: `/select-doctor?patientId={id}`
- Мои записи: `/appointments?patientId={id}`
